# 🌐 국경없는 수달들 (SAI)

DeepL 및 Google Gemini API를 활용하여   AI 기반 텍스트 분석을 제공하는 서비스입니다.
혹시 몰라 다른 분들이 하실 떄 안되면 연락주세여~ ai 두 개를 쓴 건 그냥 다른 친구가 순수 번역은 제일 좋다고 해서 써봤습니다. 서현님 화이팅입니다. 
---

## 🛠 썻던 것들

### Backend
- **Language:** Java 17+
- **Framework:** Spring Boot 4.x
- **Build Tool:** Gradle

### Frontend
- **Library/Framework:** React
- **HTTP Client:** Axios
- **Icon Set:** Lucide React
